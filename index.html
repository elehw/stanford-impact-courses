Reading an empty field. A blank CSI area, theme or ecopreneurial objective means the programme that maintains that list has not assessed this course — never that the course does not qualify.

Timetables. A course marked not yet scheduled is in the catalogue but had no class listed for 2026-27 when this was last checked (October 2026). It may still be added, so check Navigator before planning around it.

Theme and Capability. Theme says what a course is about — adapted from the MSx CSI survey verticals. Capability says what you will be able to do after it — derived from the CSI certificate's own Area concepts. Both are read from the course description and both can be empty; a pure science course teaches a subject without building a professional capability.
