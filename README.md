# Stanford Impact Course Finder — beta

A filterable finder for Stanford's social and environmental impact courses, 2026-27.

Compiled from the CSI Certificate course list, the E-IPER course list, Sustainable
Stanford's 2024-25 sustainability course list, the five Doerr School graduate
certificate lists, and the Ecopreneurship Resource Landscape. Titles, units, quarters
and teaching staff are cross-checked against ExploreCourses, the registrar's catalogue.

This is a student project. It is not an official Stanford tool and carries no
endorsement from any school, programme or centre. Always confirm a course on
ExploreCourses or Navigator before you register.

Eleonore Windisch, MSx '26

## Publishing

`index.html` is the whole site — one self-contained file, no build step.
Any change: replace `index.html` and the live page updates within a minute.
